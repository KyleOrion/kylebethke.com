# Kyle Bethke - Personal Portfolio

My personal portfolio website built with Next.js, React, and Material-UI.

## About

This is my portfolio website where I showcase my projects and learning journey as a developer. I'm learning web development and building cool stuff!

## Tech Stack

- **Next.js 16** - React framework with App Router
- **React 19** - UI library
- **TypeScript** - Type safety
- **Material-UI (Joy)** - Component library
- **pnpm** - Package manager

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm (install with `npm install -g pnpm`)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/kylebethke.com.git
cd kylebethke.com

# Install dependencies
pnpm install

# Run development server
pnpm dev
```

Open [http://localhost:3004](http://localhost:3004) to view the site.

## Available Scripts

- `pnpm dev` - Start development server on port 3004
- `pnpm build` - Build for production
- `pnpm start` - Start production server
- `pnpm lint` - Run ESLint
- `pnpm type-check` - Check TypeScript types
